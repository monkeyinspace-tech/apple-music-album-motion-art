# Política de segurança

## Versões suportadas

| Versão | Suportada |
|---|---|
| 2.x | ✅ |
| < 2.0 | ❌ |

## Reportar vulnerabilidades

Se você encontrou uma vulnerabilidade de segurança neste projeto, **não abra uma issue pública**.

Envie um e-mail para: **security@monkeyinspace.tech** (ou abra uma [Security Advisory](https://github.com/monkeyinspace-tech/apple-music-album-motion-art/security/advisories/new) privada).

Inclua:
- Descrição da vulnerabilidade
- Passos para reproduzir
- Impacto estimado
- Versão afetada

Responderemos em até 7 dias úteis.

## Escopo

- Vulnerabilidades no código Python (injeção, path traversal, execução arbitrária de plugins).
- Exposição de dados sensíveis em logs ou outputs.
- Problemas de segurança em dependências.

## Fora de escopo

- Vulnerabilidades em dependências de terceiros (reporte diretamente ao mantenedor).
- Problemas de performance ou bugs funcionais (use as issues normais).
